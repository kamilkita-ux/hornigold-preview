# Wersja 23.16 — kontrola ochrony integracji

Zawiera lokalne narzędzie kontroli hashy wskazanych plików rezerwacji/Fiserv, sześć testów ochrony, instrukcję dla wdrażającego, odświeżony rejestr 34 punktów i dowody odbioru podglądów 23.15. Nie zmienia interfejsu, kodu ani konfiguracji istniejącej integracji rezerwacji/płatności.

Właściciel polecił publikować kolejne sprawdzone wersje GitHub i podglądów bez oczekiwania na Marka/Cloudflare. Produkcję potwierdzamy odrębnym publicznym odczytem. Podglądy zachowują noindex i wyłączoną analitykę.

Kontrola hashy wymaga rzeczywistej listy chronionych ścieżek od Marka. Nie dowodzi działania PMS/płatności i nie jest jeszcze podpięta do produkcyjnego pipeline.
